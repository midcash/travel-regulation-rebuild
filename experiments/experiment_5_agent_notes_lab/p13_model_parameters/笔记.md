# 第 7 章 · 大模型参数设置

> 对应原文：顶层 `07-Agent开发框架与工程实践.md` 第 7 章
> 对应原型：`p13_model_parameters/`

## 形状

```text
logits
  ├─ penalty：根据历史 token 改分数
  ├─ temperature：softmax 前缩放分布尖锐度
  └─ top_p：按累计概率裁剪候选集合
        ↓
      采样 → max_tokens 截断
```

## 知识点总括

- `temperature` 越低越确定，适合分类、抽取、代码和分析；越高越多样，适合创意任务。
- `top_p` 控制核采样候选范围，通常保留 0.9~0.95；实际调参不建议和 temperature 同时大幅变化。
- `max_tokens` 是输出预算，不是质量参数；结构化输出要预留字段和结束标记空间。
- `presence_penalty` 按是否出现过惩罚，`frequency_penalty` 按出现次数累积惩罚；值过高可能伤害连贯性。
- 参数只改变生成分布，不会修复事实错误、工具 Schema 错误或业务流程错误。
- 分析型 Agent 可采用低 temperature、top_p 默认、低 penalty；参数选择应由任务稳定性、准确性、创造性和成本共同决定。
