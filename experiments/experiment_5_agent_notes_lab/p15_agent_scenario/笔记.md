# 第 15 章 · Agent 场景题

> 对应原文：顶层 `07-Agent开发框架与工程实践.md` 第 15 章
> 对应原型：`p15_agent_scenario/`

## 形状

```text
确定性入口/路由挡住大多数流量
        ↓
有界 Agentic Loop：选择哪些 Worker、证据是否够、是否继续取证
        ↓
确定性评分与分档：放行 / 加验证 / 拒绝 / 转人工
        ↑
异步真实标签：更新用户画像、模式库、阈值
```

## 知识点总括

- 场景题先从触发层、Agent 架构、业务逻辑三个维度建立骨架，再补数据和风险边界。
- 实时风控采用“固定骨架 + 有界 ReAct”：流程需要可预测，但取证维度和追加取证可以由模型动态选择。
- 多 Agent 不等于无限并行；应预定义 Worker 编制、并行上限、单 Worker 工具边界和只返回摘要的接口。
- Critic 应在综合证据之后独立复核，位置太早看不全，给每个 Worker 都配重 Critic 又会拖垮延迟。
- 输出不是一个分数，而是绑定动作的风险分档；灰区应有加验证缓冲，高额/低置信/分歧要人工兜底。
- 真实标签通常事后回流，才能更新画像、欺诈模式和阈值，也才能计算 Recall/Precision。
