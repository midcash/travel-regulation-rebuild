## 形状

```python
entry = append(type, content, parentId=current_leaf)
current_leaf = entry.id

path = get_path_to_root(current_leaf)
context = build_session_context(path)  # 只喂当前链
```

## 知识点总括

- Pi 的核心理念是 `grows with you`：默认只给 read、bash、edit、write，其他能力由扩展补齐。
- 四个 package 可按依赖方向理解：`coding-agent → agent → ai`，`coding-agent → tui`；核心 Agent 不依赖终端 UI。
- AgentLoop 的基本顺序是 Context 组装 → Compaction 检查 → 调模型 → 工具循环 → 写入会话；流式输出、中断和 follow-up 是工程细节。
- 会话采用 JSONL + append-only + `parentId`。树是存储形态，当前 leaf 到 root 的链是模型看到的形态。
- 回退只改变当前位置，不删除历史；压缩只追加摘要节点，不改写旧消息。
- 压缩要保留任务状态、决策、TODO 和工具调用对；遇到 context overflow 可压缩后重试。
- Pi 的内核只回退对话，不回退代码；如需代码一起回退，可通过 Git checkpoint 扩展补上。
- Skill 的加载是“描述进入系统提示词 → 模型判断 → 用 read 按需读完整 Skill”，不是把所有 Skill 全文常驻上下文。

## 反直觉点

1. 回退看起来像删除了对话，实际只是换了 `leaf`。
2. 压缩看起来像改写历史，实际只是多了一个 `compaction` 条目。
3. 会话树和模型上下文不是同一个东西：文件里保留所有分支，模型只看当前路径。

运行 `main.py`，再打开生成的 JSONL 文件核对这些结论。
