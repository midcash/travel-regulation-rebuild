    试试能力边界

    /note 内容
    调用工具保存笔记
    /calendar JSON
    新增日程，字段 title、start、end、timeZone；默认固定 UTC+8（+08:00），时间含时区偏移，例如 2026-11-06T15:00:00+08:00。
    /events JSON
    按 start、end 查询日程
    /update JSON
    修改已有日程，eventId 为查询返回的 ID；仅传入要修改的 title、start、end、timeZone 字段。
    /delete JSON
    删除已有日程，传入 eventId。
    /slow 内容
    十秒工具，可取消或重启恢复
    /fail
    观察工具失败及后续对话

    以上命令仅适用于离线演示。真实模型模式请用自然语言。支持读取、新增、修改、改期和删除单次定时日程。
