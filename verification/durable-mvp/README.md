## 离线进程检查

```powershell
python -B -X utf8 -m unittest discover -s verification/durable-mvp -v
python scripts/check.py
```

[test_mvp.py](test_mvp.py) 使用真实 HTTP、Node、Pi Durable 和 SQLite。每项新建临时目录，只在自身重启间复用；子进程不继承模型凭证，离线宿主拒绝外连。替身只在 pi-ai 模型边界。

- 笔记保存后模型/工具精确为 `(2, 1)`，重复请求不新增调用。强杀整个宿主后恢复，消息和笔记相等，新进程为 `(0, 0)`；重试原 ID 仍不新增调用，同 ID 不同正文返回 409。
- 慢工具开始后强杀，恢复只重放中断工具和后续模型，精确为 `(1, 1)`，用户消息仍只有一条。
- 执行中取消后回到 idle，可以继续下一轮。
- 失败工具产生带 error 的真实工具结果，后续对话可继续。
- 后台任务进入 sleeping 后取消普通轮次、强杀重启，到期完成；再重启仍为原任务，不调用模型或工具。
- 只读轮询不产生调用；拒绝跨 Origin、错误 Content-Type 和空输入。带 `charset` 参数的 `application/json` 正常接受；超过 16 KB 的请求返回 413，未读 body 即拒绝的 413/415 会关闭连接。
- 同一数据目录拒绝第二个宿主，不影响第一个；独占 SQLite 锁在强杀后由系统释放，各用例的强杀重启步骤覆盖该路径，不需要手工清理锁文件。锁库损坏等非争用错误按原始错误上报，不伪装成占用。
- HTTP 分块在中文 UTF-8 字节内部断开时，笔记仍完整保存。
