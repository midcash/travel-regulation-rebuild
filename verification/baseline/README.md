从旧回归保留以下验收意图，均尚未在 Durable 差旅路径验证：

- B09/B11：本地校验、缺配置与供应商失败区分；本地失败不伪称供应商观察。成功与空候选记录观察时间，失败尝试保留证据但不伪造成功观察；不泄露原文或密钥。
- B08：刷新/读取不新增调用，可靠成果保留；服务重启及隔日恢复需验证业务选定项。
- B11/B12：失败后保留可靠成果，未知费用不补零，限制工具范围，选定不产生订单付款。
