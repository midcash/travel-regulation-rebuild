# HIL 分阶段实施记录

## 阶段 1：固定非交互兼容基线

范围：批准的兼容约定与实现前回归断言；不改生产代码。

验收（2026-09-11）：`python -m unittest discover -s tests -p <文件名>` 分别运行 test_travel.py（12）、test_policy.py（6）、test_transport.py（14）、test_integration.py（3）、test_loop_contract.py（7），合计 42 个测试通过。

新增断言固定 provider 异常分类、非法响应先记账、响应后 token 阻断、最后一轮 finish、同轮重试及重试预算、工具异常、初始化和最终保存的外抛边界。原交通测试继续覆盖三次请求与两次重试。

本阶段只证明当前代码基线，不证明 HIL 已实现。tests/test_transport_detail.py 为开始前已有未跟踪文件，不修改、不纳入本次提交或验收范围。未调用真实供应商 API。

## 后续阶段及门禁

2. 共享执行内核与工具状态：旧入口回归、逐步恢复等价、错误分支和预算变异检查。
3. 持久化 HIL：跨进程、多次等待、预算连续、原子消费、并发所有权、证据约束和故障恢复。
4. HTTP 与页面：等待释放线程、刷新与重启恢复、公开数据隔离、既有接口兼容及隔离安装。

各阶段通过后独立提交；未通过不标完成。后续尚未接入的真实工具业务联调继续属于原工单依赖。

## 阶段 2：共享执行内核与状态

将模型回合与工具分派分离到 TripExecution，plan_trip 仍同步驱动同一内核至终态。demo 同轮重试留在 dispatch 内；工具显式导出/恢复 JSON 状态，客户端不序列化。恢复检查版本、模型/价格、提示词、工具 schema、数据和政策来源。

验收：阶段 1 的 42 个测试继续通过；新增 7 个状态测试通过，合计 49 个。逐边界 JSON 往返的最终业务结果与旧入口相同；pending 分派不再调用模型；恢复保留剩余 170 秒预算和未知费用。预算重置变异被测试检测。独立上下文审查发现墙钟耗时和自定义政策来源恢复缺陷，均已修复并增加复现测试。

本阶段快照是执行内核接口；尚不提供并发安全的公开恢复服务。数据库事务、执行所有权、inflight 崩溃处理与消息协议检查属于阶段 3。

## 阶段 3：持久化人工交互

新增 start_trip/get_trip/respond_trip/resume_trip/cancel_trip。独立 SQLite 表保存私有快照；OS 文件锁与数据库 owner/version 防止同机多进程重复执行。答复幂等、等待 TTL、人工配额、候选来源与选择约束均在应用侧检查。默认创建一次需求确认，模型可继续发起偏好/确认/候选问题；真实交通多个候选可由程序发起选择。拒绝候选可继续查询，显式取消单独结束任务。

验收：67 个适用测试通过（原有 35、循环契约 8、执行状态 7、HIL 17）。包含三个独立进程完成两次暂停、双回复竞争、跨进程执行锁、进程强制退出后的 inflight 不重放、最终保存失败恢复，以及固定 HTTP 响应下 real 三次查询/两次重试历史延续。预算检查跳过、忽略确认、错误选择的变异均被检测。阶段 2 的预算重置变异继续适用。

独立审查发现提前显示终态、非 assistant 人工调用与拒绝确认未约束结果三项问题，均修复并加入复现测试。已知 real 裸 TimeoutError fallback 缺少 call_id 的问题显式修正并增加断言。公开 run/trace 不包含私有消息或人工快照。

当前真实工具已接入政策、交通、住宿、地点解析和两段驾车路线；路线使用 HIL 选择后恢复的地点候选 ID，保留每段独立证据与查询时耗时语义。#7 的固定 HTTP 响应与 HIL 合同验收见 [工单 7 验证记录](issue-7-verification.md)，真实供应商线上整链仍由后续联调承担。HIL 不修改真实 API 名称和参数；后续工具需要继续扩展 human.check_decisions 的明确字段映射，并增加对应业务断言。

## 阶段 4：HTTP、页面和隔离验收

新增 /api/hil/runs 及查询/respond/resume/cancel 入口，沿用本机、同源、JSON 与请求大小限制。页面提供显式交互开关、问题/候选、回复、取消和继续处理；等待释放 worker。原 run/jobs/evaluation 默认行为不变，HIL 规划性能按活跃执行时间统计。

验收：71 个 Python 测试全部通过；Node 前端测试覆盖异步切换任务的原子显示、操作绑定原任务和候选 ID 与拒绝操作隔离。独立审查发现的两个前端问题已修复。另补充端点恢复核对，以及无 provider 凭证也能取消/补收尾的测试；执行快照版本为 2，不支持恢复中间开发版的未完成版本 1 快照。

浏览器人工操作验收使用独立 artifacts/hil-ui-verification.sqlite3、baseline、demo：创建等待 → 页面刷新 → 停止并重启服务 → 原 Trace 回复 → 页面显示 628 元完整方案、4 次工具调用；随后新建任务并取消，页面显示已取消且模型/工具均为 0。未使用真实模型或供应商网络。前端快速切换的竞态另以 Node VM 确定性复现与回归，不以浏览器偶然成功代替。

本地 wheel 构建及独立目录安装已验证，无 experiments 目录的安装可以通过 start/respond 得到 628 元、4 次工具调用的终态。pip 默认用户缓存曾被沙箱阻止，改为无缓存本地构建成功。原有未跟踪 tests/test_transport_detail.py 保持不变且未提交。

入口说明见 [HIL 使用说明](../hil-usage.md)。远程 GitHub 工单未修改，真实 API 整链成功验收仍由原后续工单承担；当前离线与固定 HTTP 响应的验收不替代该验收。
