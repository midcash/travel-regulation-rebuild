# ADR 002：转为个人日程助手，差旅作为子能力保留

状态：已决定，2026-11-05，落实用户明确决定。不补写此前未记录的原因。

产品定位由"个人差旅助手"调整为"个人日程 Agent 助手"。差旅作为日程助手的子能力保留；除业务范围表述（范围一节与 B12）放宽为日程助手当前支持的能力外，其术语与 B01–B12 的既有业务语义不变。

- 日程能力的术语与验收场景另行确认后新增，本决定不定义日程业务规则。
- Pi Durable 仍是唯一维护的 Agent 运行路径。包名 `travel_agent`、项目名和仓库名本次不改。
- RealTools、供应商适配、事实结构和 Trace 作为差旅子能力资产保留，仍未接入 Durable。

本决定只调整文档定位，不实现任何日程功能，也不代表差旅业务迁移完成。
