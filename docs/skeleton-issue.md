# 工单草案：搭建可测试的 Pi 差旅会话骨架

状态：待建单、待实现。先完成这一张纵向工单，再按真实验收缺口推进 B01–B12；不按 Node/Python/页面机械拆成多个相互等待的工单。行为唯一依据为 [product-behavior.md](product-behavior.md)，技术决定见 [pi-migration-plan.md](pi-migration-plan.md)。旧 GitHub #11–#30 需要维护者同步新的推进方式；本草案不表示已更新远端工单。

## 交付

用户在本机页面创建会话，发送明确出发地、目的地和未来日期的航班查询；Python 经正式 Node Pi 运行时调用真实交通工具，流式展示回答与带来源/查询时间的结果。刷新页面、重启服务后可查看同一会话并继续。缺凭证明确报错，供应商失败保留消息和失败信息；不切演示、不创建订单。

这是骨架的完成边界，只验这一条真实纵向链路及其失败/恢复路径，不宣称 B01–B12 全部实现。后续工单补业务行为，不能再替换一次存储或运行架构。

## 实现边界

- 一个默认启动命令、一个本地页面、一个会话服务；Python 管理按会话隔离的 Node Pi SDK 1.3.0 子进程，SQLite 唯一持久化；正式 runtime 不导入 verification，也不自写 Agent loop。
- 每条消息记录上海当前时间；供应商执行时重新检查日期。接入交通工具时解除会议时间必填；搜索所需字段就是城市和出行日期，不能捏造会议字段来迎合旧适配器。其他工具按需逐步接入，不为凑齐七个工具强制增加行程段。
- 持久化消息、SDK entries/压缩记录、run、工具请求与结果证据、事件游标；事务先提交再交模型/页面。重启把未结束运行标 interrupted，不自动续费重放。保留旧数据库表；测试始终用临时库。
- 创建/读取会话、提交消息、读取状态、SSE 和取消足够支撑骨架；重复消息 ID 幂等，同 ID 不同正文拒绝；同一会话单运行，不同会话不串内容。断线只退订，取消停止后续模型/工具；在途未知用量明确标记。
- 工具返回紧凑事实、证据 ID、抓取时间、实际参数及错误/覆盖限制；私有原始结果不直接灌给模型或页面。保留已有输入校验、脱敏和 HTTP 上限。选定项/条件版本接口在需要时实现，不能把模型文字当成已提交状态。
- 只绑定回环地址，校验 Host/Origin/客户端头；模型没有文件、Shell、coding tools、项目指令或用户目录访问。供应商密钥留在 Python；推理不导出到页面/OTLP。
- 模型/工具/HTTP/缓存与摘要用量、取消及失败可追查，执行已确认熔断和日累计保护；价格未知就记 unknown。

## 必须随骨架交付的测试

- **白盒**：会话事务、消息幂等与冲突、证据归属、条件/取消状态、跨午夜日期、进程退出/重启。断言状态与证据，不绑定回答措辞。
- **API 黑盒**：启动正式服务、临时数据库、临时端口和固定时钟；通过 HTTP/SSE 验证正常查询、供应商失败、无凭证、重连、重复消息、取消和跨会话隔离。测试直接走正式桥接和工具适配器；只在模型传输和供应商 HTTP 边界注入替身。
- **浏览器端到端**：锁定 Playwright 测试依赖与浏览器安装步骤；一条命令自动启停服务，用可定位的可访问控件完成创建会话→发消息→看到非空结果/来源→刷新→重启后恢复。失败输出截图、Trace 和服务日志，不调用旧页面或只测 JS 字符串。
- **真实端到端**：独立显式命令，使用现有 DeepSeek/途牛凭证及当次未来日期，从页面走正式链路；记录版本、输入、Trace、截图、用量及供应商证据。先估算成本，按日保护执行；缺凭证是未验收，不把离线结果冒充真实通过。骨架航班链路通过后，再对含酒店/地点/路线的真实三亚场景验收。
- **可复现**：新克隆按文档安装后，默认一个命令跑完不收费检查；缺 Node/SDK/浏览器明确失败，不能静默跳过。CI 执行相同命令，测试不依赖本机历史记录或固定历史报价。

## 验收方式

实现者在工单中逐项给出上述命令及结果，并列出 B01–B12 哪些尚未覆盖。正常路径和故障路径均走正式运行链路；工具单测、第 0 步探针或健康检查成功，都不能单独关闭骨架工单。
