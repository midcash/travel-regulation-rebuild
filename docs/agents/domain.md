# Domain docs

This is a single-context repository. If present, read `CONTEXT.md` at the repository root before exploring domain behaviour, then read relevant records under `docs/adr/`.

If these files do not exist, proceed without creating them unless a domain-modeling session resolves a term or decision that needs to be recorded.

Use the vocabulary defined by the glossary in issues, tests, and implementation discussions. Surface conflicts with existing ADRs instead of silently overriding them.
