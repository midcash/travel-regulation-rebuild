日期：2026-10-16。用户已授权安装、模型实测、修复基线、关闭旧工单、提交并推送。本步不切换生产入口。现场提交为 `0b7364f`；基线修复另建提交，最终报告记录准确 SHA。

## 通过与失败条件

每项报告 PASS、FAIL 或 BLOCKED；网络、凭证、余额、供应商或工具故障不能记为通过。确定性测试不能替代真实 DeepSeek 测试。

1. **可重复基线**：旧上限恢复 10 轮、12 工具、24,000 token、3 次人工请求；固定回归保留 2026-09 日期和固定时钟，页面示例按服务端上海当前时间相对生成。Python 回归、三个 Node UI 测试及 baseline eval 通过才 PASS；不删除或放宽独立 oracle。记录运行解释器与提交。
2. **安装与型号**：锁定 Pi SDK 1.3.0 及 lockfile；读取现有配置，不输出凭证；选定可用 DeepSeek 型号，记录请求型号、响应型号和推理配置。安装或真实请求未成功则对应项失败或受阻。
3. **工具、流式和 usage**：真实模型发出工具调用，固定工具结果经过 SQLite 提交后送回 Node，模型据此回答；收到文本增量与完整最终消息；记录 input/output/cacheRead/cacheWrite/totalTokens、原始 usage 字段是否存在、推理增量及最终推理内容是否存在。缺失计量不能填零冒充；分别报告支持与不支持。
4. **steer 与取消**：在工具等待时注入 steer，后续响应响应新指令；取消中的请求在限定时间内结束，后续不再启动工具。按钮运行中先落库再 steer，空闲只落库且模型请求数不变；下一轮上下文有选择。
5. **内存恢复**：从外部 entries 注入历史消息、工具结果和压缩记录，创建内存 SessionManager；从 SQLite 重建后选定项、证据与压缩语义仍在，且不生成会话文件。通过即不使用 Pi 会话文件；失败才论证缓存替代，不悄悄换实现。
6. **压缩**：真实模型执行压缩、统计其用量；压缩后注入 SQLite 有效选定项、证据 ID、查询时间与摘要，后续回答能引用；重建仍有效。仅调用压缩 API 未产生压缩记录不算通过。
7. **资源隔离**：Pi cwd、HOME/USERPROFILE、Pi 配置路径均指向空临时目录；内存配置、自定义 ResourceLoader。在加载 SDK 前挂钩 Node 文件系统入口，记录读/扫描/写路径，仓库 AGENTS.md、.agents 与真实用户配置目录访问为零；加入恶意访问负向断言证明探针有效。依赖包与操作系统必要资源不等同于项目资源，单独允许。
8. **Windows 生命周期**：Python 创建 Node，正常退出、取消、强制终止、异常退出和重启均有结果；stdin/stdout 协议无日志污染，关闭后无该子进程存活，未完成请求不会永久等待。
9. **SQLite 与幂等**：消息保存上海捕获时间与条件版本；工具结果先提交，再答复 Node。模拟供应商返回但提交前崩溃时保持 unknown，新查询使用新 ID；重复投递已完成调用读取已存结果，不重复执行。新增表不改旧表，旧 Store/HIL 能读取原库；旧等待任务切换后只读为后续迁移要求，本步不批量修改用户任务。
10. **观测**：模型/工具/压缩/取消事件带关联 ID 回到 Python Trace，经 Python OTLP 导出；本地接收端验证 OTLP 有模型 span 和 token 属性。流片段不逐个建 span，不导出提示词、推理正文与密钥。
11. **回放**：正常、历史失败重试、中途修改、压缩恢复四类各运行 3 次（若发现不稳定再增加至 5 次），报告全部运行及 min–max，不只选成功样本。以捕获的固定上海时钟告知模型。仅允许匹配工具名和实际查询参数的数据回放；未匹配返回“无历史数据”并统计覆盖，禁止在线回退、错误参数复用或编造数据。历史仅有供应商响应时明确标记为新模型运行。
12. **预算**：按实际计量分别统计模型、工具、HTTP、重试、压缩和 token。根据完成率、范围与覆盖提出初始预算；未完成或覆盖不足不能通过增加预算伪装成功。历史样本不足不声称 p95 或生产上限已校准。

## 已确定的迁移边界

- SQLite 是恢复事实源；优先完全内存 Pi 会话。新消息/模型/工具/压缩 entries 持久化到 SQLite；Pi entries 的格式跟锁定版本，升级需显式兼容测试。
- 首版会话级条件版本号；结果保留启动版本和实际查询参数，历史可留存，旧版本不可覆盖当前成果。
- 上海捕获时间固定相对日期含义；实时供应商调用前再检查执行日期，历史回顾不调用实时接口。
- 页面按钮经后端校验候选、版本、幂等键后事务写库；运行中 steer，空闲不触发模型。
- plan_trip 短期保留为统一会话的一次性兼容入口；CLI serve/run/trace 保留，eval 分开旧回归与 B 场景；无凭证演示使用 Pi 内确定性假模型，baseline 自检新路径，不代表 LLM 质量；旧循环/HIL 最终退出生产执行。
- 第 2 批分成保持现有行为接通成果区、按 B01–B12 逐项放开。切换时旧等待 HIL 标为旧版只读；旧表与字段保持不变，回滚不得损坏新数据。
- #1–#10 按 not planned 关闭，说明被 product-behavior.md 取代；未完成真实链路验收建立承接工单。新迁移子工单在第 0 步完成后依据实测编写。
