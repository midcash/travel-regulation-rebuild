## 已确定的方向

- Python 管理按会话隔离的 Node 子进程；使用精确锁定 Pi SDK 1.3.0 的内存会话，SQLite 为唯一存储。正式 runtime 不导入验证 worker，不自写 Agent loop。
- 会话的消息、SDK entries（含工具/推理所需结构和压缩记录）、运行、证据及递增事件都持久化；结果先事务提交，再交模型和 SSE。取消先落库，重启将残留运行标 interrupted，不自动续费重放。
- 同会话单运行、命令串行，跨会话隔离；消息/工具 ID 幂等，同 ID 不同内容拒绝。unknown 工具请求不能自动重放，新查使用新 ID。
- 明确采纳/修改才更新选定项并递增条件版本；比较不改选择。选定按钮事务校验证据、候选归属和 expected_version，冲突返回 409；空闲选定不调用模型，运行中用 steer。旧版本迟到结果只归档，按实际变化判断可复用部分。
- 每条消息捕获上海时间，每次供应商执行重读当前日期；历史解释使用历史证据及查询时间，当前价格/可用性需重查。摘要不能覆盖数据库中的有效条件和选择。
- 工具返回精简事实、实际参数、证据 ID、查询时间和限制；原始结果留私有证据存储，不反复注入模型。先应用有效筛选再截最多五条，未知和无覆盖明确表达。
- 页面由历史、交互和成果组成；绑定回环地址，保留 Host/Origin/客户端头及输入大小校验。SSE 重连有游标，先读一致状态与事件序号再订阅；断线仅退订，不取消运行。
- 用户取消后停止排队和后续模型/HTTP；Node 工具 AbortSignal 传到 Python。不可撤销的在途请求保留未知状态；十秒不退出则终止子进程，迟到结果不应用到当前条件。
- Node 仅获得模型凭证，供应商密钥留 Python；空临时 cwd、重定向用户配置目录、内存资源加载器，无文件/Shell/coding tools/项目技能。正式隔离回归覆盖祖先目录、真实 home、配置文件与 symlink/junction 绕过；第 0 步探针不是恶意代码系统沙箱。
- 不兼容旧 plan_trip/baseline/HIL 产品合同，不投影旧测试任务；旧 SQLite 表和数据保留原样。默认缺凭证明确错误，不切假模型。

## 计量、重试与防失控

2026-10-18 已确认、尚待正式 runtime 实现：开发阶段完整计量，单请求模型 30 次、工具 50 次、累计 50 万 token、活跃 10 分钟、单模型 45 秒；触发停止排查，不自动加额。项目上海自然日跨会话累计人民币 50 元，金额 unknown 时每日 500 万累计 token，重启不重置。真实模型测试前估算总 token/金额（未知记 unknown），预计超限先停止汇报。

总输入为 Pi input + cacheRead，输出已含 reasoning，不重复加；缺失和取消用量不填零。记录模型/摘要/重试/工具/HTTP、版本、耗时和 usage_complete。推理只在私有恢复结构中保留，不输出页面或 OTLP。探针中的模型容量和零价元数据仅用于历史接入测试；正式型号、容量与价格需实施时核实，不自动换型号或声称零费用。

模型网络重试由 Node 的一个适配层负责，SDK 隐式重试关闭，Python 不重发 prompt；仅 429、可恢复 5xx、未输出流的连接失败最多重试一次，受 Retry-After/超时/熔断约束。已输出流后中断不自动重试，认证/参数/上下文超限不重试。供应商自动重试为零，模型重查作为新请求计量。压缩失败不叠加重试层。

正式预算待 B01–B12 验收后据真实数据优化；不得把旧短历史样本的最大值当作产品成本门禁。
