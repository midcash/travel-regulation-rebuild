**394,607 token / 104 次工具 / 63 次模型，是十二次累计**：normal、retry、redirect、compact_restore 各三次；14 次工具返回 NoHistoricalData。压缩恢复组含摘要与恢复回答，不能当一次普通三亚流程。

Pi + DeepSeek 模型调用真实发生，但供应商结果取历史夹具，本批真实供应商 HTTP 为零。历史三亚 summary 只有供应商工具数据，没有可复算的旧 Agent 模型账单。完整生产 API→Pi→真实供应商→页面的单次三亚数据尚不存在，不能补造；由 M03b 产生。

## 单次完整工具覆盖三亚回放

normal 中两次历史工具覆盖 100%、零 NoHistoricalData，可作为现有单次流程数据；这不是生产真实链路或 B 场景验收：

- **trial 1**：模型 **4** 次、工具 **9** 次、历史 HTTP 15 次；未命中输入 **9,946**，命中输入 **16,384**，总输入 **26,330**，输出 **1,606**，合计 **27,936 token**，14.16 秒，usage_complete=true。
- **trial 2**：模型 **5** 次、工具 **9** 次、历史 HTTP 15 次；未命中输入 **9,995**，命中输入 **24,832**，总输入 **34,827**，输出 **1,660**，合计 **36,487 token**，15.55 秒，usage_complete=true。

normal / trial 3 为模型 4、工具 10、28,180 token，有一次无历史数据、覆盖 90%，不能充当第三次完整覆盖成功。

十二次单次最高值分别为模型 7、工具 13、历史 HTTP 18、49,196 token、29.39 秒，各维度不一定来自同一次。最大 token 样本 compact_restore / trial 2：未命中输入 18,050、命中输入 27,520、输出 3,626；总输入 45,570，总计 49,196，包含摘要/恢复，有一次无历史数据。它用于保守成本留量，不作为完整业务成功。

## 计量口径与开发控制

累计 token 包含缓存命中的输入，逐请求累加 input+cacheRead+cacheWrite+output，与原始 prompt_tokens+completion_tokens 交叉核验，推理已含输出不重复加。缓存只影响价格，不从计量中扣除。原始接口未独立报告 cache-write，规范化零值不能证明收费为零；中断或未知用量不填零。

历史复算：十二次模型 63、工具 104、token 394,607；trial 1 的 9,946+16,384+1,606=27,936，trial 2 的 9,995+24,832+1,660=36,487，最大 token 样本 18,050+27,520+3,626=49,196。短历史数据不能代表多轮后段或真实供应商时延，也不转成迁移预算通过条件。

开发阶段只完整计量和防失控熔断：单请求模型30次、工具50次、累计500,000 token、活跃10分钟、单模型45秒；HTTP和其他维度记录实际值，不保留旧独立HTTP预算。计量覆盖尝试/执行、缓存/未命中、输出/推理、摘要/重试/取消和耗时，进入Trace/OTLP及报告。熔断触发停止并按缺陷排查，不自动加额、不以调高值代替排查。真实三亚只要求在熔断内成功并完整计量，不另设省钱或样本余量门禁。

项目每日总花费默认人民币50元；金额unknown或无法可靠换算时按每日5,000,000累计token（含缓存命中），不视为价格等值。上海自然日跨会话、进程、测试共享，SQLite持久化、重启不重置，并发预计占用须纳入检查。未知用量保留标记和预估占用，不能填零释放额度。

## M04b 数据收集与执行前估算

保留首轮和改口样本，增加待发上下文30–36k、42–48k两档，B05修改查询/B08重启恢复后查询/B09隔日当前价格核验三类；每档每类先一次、共六次，可按问题追加，报告全部样本、不筛选，不设固定重复次数或用量门禁。采用相关多轮消息/工具/证据/压缩记录，准备历史与后段分别计量。T低于48k时两档等比例取T的62.5%–75%、87.5%–100%，报告实际规模和压缩/摘要成本。

付费模型测试执行前，按完整批次的样本数、上下文、预计模型轮次、输出/摘要/重试估算总token与金额，注明范围和假设；价格未知写unknown，不能假设免费。加当日已用及在途占用后，预计超日金额/降级token上限，先停止并汇报，不自行缩样或扩额后开跑。回放只报告其实际耗时，真实供应商耗时在M03b记录；触发开发熔断则停止并排查，不把调高阈值作为验收补救。

结论：数据供预算优化参考。正式预算在B01–B12完成后，由“预算优化”工单依据真实数据设定并逐步收紧，压缩阈值、工具结果精简等优化一并评估。不得以这些历史样本或模拟token代替新实测。
